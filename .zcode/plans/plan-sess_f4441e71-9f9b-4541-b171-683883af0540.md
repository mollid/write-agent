# 为 novel CLI 增加 Web GUI

## 方案

FastAPI 后端（复用现有引擎）+ 无构建步骤的原生 HTML/JS 前端，浏览器访问。第一版做核心闭环：新建/打开项目 → 生成概念 → 生成章节（实时进度 + 审批按钮）→ 查看/导出章节与伏笔。

引擎是同步阻塞的（`run_full_pipeline` 无 async），GUI 用后台线程跑流水线，SSE 推送进度，审批门控通过 `threading.Event` 阻塞等待浏览器点击。

## 引擎侧最小改动（保持 CLI 行为不变）

1. `novel/graph.py`：给 `run_full_pipeline` 增加可选参数 `on_event: Callable[[dict], None] | None = None`，在关键节点发出事件（setup 各阶段开始/完成、每章 writer/scorer/continuity/editor 阶段、章节保存、重写重试、出错）。默认 `None`，CLI 不传则行为与现在完全一致。
2. `novel/cli.py`：把 `_make_provider` / `_demo_provider` 的选择逻辑提取为可复用函数（如挪到 `novel/providers.py` 或新的 `novel/runtime.py`），CLI 与 GUI 共用，避免 GUI 直接 import CLI 模块。

## 新增 `novel/ui/` 包

```
novel/ui/__init__.py
novel/ui/app.py     # FastAPI 应用工厂 + 路由
novel/ui/jobs.py    # JobManager：后台线程执行流水线、审批桥接、事件广播
novel/ui/static/    # index.html + app.js + style.css（原生 JS，无构建）
```

### API 设计

- `GET  /api/projects` — 扫描工作区下含 `project.config.yaml`/`bible/` 的目录，列出项目
- `POST /api/projects` — `{name, genre}` → `NovelProject.scaffold`
- `GET  /api/projects/{p}/status` — 概念/世界观/大纲就绪状态、章节列表、未闭合伏笔数、当前任务状态
- `POST /api/projects/{p}/premise` — `{text}` 后台线程执行（同 CLI premise 逻辑）
- `POST /api/projects/{p}/write-chapter` — `{n}` 后台线程执行 `run_full_pipeline`
- `GET  /api/projects/{p}/chapters/{num}` — 返回章节 Markdown
- `GET  /api/projects/{p}/threads` — `StoryBible.list_foreshadow()`
- `POST /api/projects/{p}/export` — `export_markdown`
- `GET  /api/projects/{p}/events` — SSE 流：进度事件 + 审批请求 + 任务结束
- `POST /api/gates/{gate_id}` — `{approve: bool}` 解除阻塞的审批
- `POST /api/jobs/{job_id}/cancel` — 取消标志（在章节间和审批等待处检查）

### 关键机制

- **审批桥接**：GUI 传入的 `on_gate(label, artifact)` 创建 Gate 对象（id + `threading.Event` + 结果），通过 SSE 推给浏览器，然后阻塞等待；`POST /api/gates/{id}` 置位 Event。等待循环同时轮询取消标志，支持中断。
- **单项目单任务**：JobManager 拒绝同项目并发任务；不同项目可并行。
- **Provider 选择**：与 CLI 一致（`NOVEL_LIVE=1` → LiteLLM，否则演示 FakeProvider），前端标注当前模式。
- **项目根目录**：默认 GUI 启动目录，可用 `--root` 参数指定。

### 前端（单页，中文界面）

- 顶栏：项目选择/新建、模式标识（演示/真实）
- 生成区：创意输入 → 生成概念；章节数 → 开始生成；进度条 + 阶段日志流
- 审批卡片：出现门控事件时弹出，显示产物摘要（截断），批准/拒绝按钮
- 浏览区：章节列表 → 点击阅读 Markdown 渲染；伏笔表（id/描述/状态）；导出按钮
- 用 `EventSource` 连 SSE，`fetch` 调 API

## 入口与依赖
